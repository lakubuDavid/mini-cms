# 034: Filter sidebar projects and guard project routes

## Description
Filter the project selector by accessible projects, fall back to the first accessible project, and block direct navigation to inaccessible project settings and collections. Hide Team/API Keys navigation and guard those routes for non-managers. Hide project create/edit/delete and API access controls for non-managers.
